# Калькулятор трудоёмкости и времени разработки

Веб-приложение для оценки трудоёмкости (человеко-месяцев) и календарного времени разработки программного обеспечения на основе моделей COCOMO и COCOMO II.

## Описание проекта

Приложение реализует классические и современные модели оценки затрат на разработку ПО. Все вычисления выполняются на стороне клиента в реальном времени с детализированым отображением формул и промежуточных результатов.

### Основной функционал

- **Базовая модель COCOMO (Basic)** - быстрая оценка трудоёмкости и времени разработки на основе объёма кода (в KSLOC или SLOC) и типа проекта (распространённый, полунезависимый, встроенный)
- **Промежуточная модель COCOMO (Intermediate)** - уточнённая оценка с учётом 15 атрибутов стоимости (надёжность ПО, размер БД, сложность продукта, квалификация персонала и др.)
- **COCOMO II — Предварительная оценка (Early Design)** - оценка на ранних этапах проекта с 5 факторами масштаба и 7 множителями трудоёмкости
- **COCOMO II — Детальная оценка (Post Architecture)** - детальная оценка с 5 факторами масштаба и 17 множителями трудоёмкости
- **Валидация входных данных** - проверка с подсветкой ошибок и подсказками
- **Детализация расчётов** - отображение используемых формул и промежуточных значений для каждой модели

## Технологии

- **HTML5** - семантическая разметка
- **CSS3** - адаптивная вёрстка с использованием Tailwind CSS, Grid Layout, Flexbox и кастомных стилей
- **JavaScript (ES6+)** - модульная архитектура на чистом JS, изоляция области видимости через IIFE
- **Tailwind CSS** - утилитарный CSS-фреймворк для быстрой стилизации

## Запуск приложения

### Предварительные требования
Для работы с приложением не требуется установка дополнительного программного обеспечения или серверных сред (Node.js, Python и др.). Достаточно наличия современного веб-браузера с поддержкой стандартов ES6+:
- **Google Chrome** (версия 90+)
- **Mozilla Firefox** (версия 88+)
- **Apple Safari** (версия 14+)
- **Microsoft Edge** (версия 90+)
